## The reversal this records

OPTIMUM's living law says coworker/lab stages "delegate: members are
minted into a child coworker program and levied once via the wake
machinery". This page records why that fold reverses: the delegation
bought composition at the price of a rendering seam that silently lost
program bytes (#195, #196, ADR 0014's hooks finding) and shattered one
run across multiple jobs and folder dialects. The maintainer's ruling:
**a job is a run of the whole thing.** Invariants that do NOT change:
programs are data (`[[stage]]` chains, refusal beats silence); minds
are delegated, fresh, briefed from one source; ordering is the chain;
verdicts are honest; one wake per commission; the window only views.

## Final (these lines are law)

- **A job is a run of the whole spur.** Components are stations, not
  jobs — the mint-a-copy, launch-a-child spelling for a same-program
  conversation stage is REJECTED. Why: one logical run became two jobs,
  two reports, two logs; the real work lived in another folder than its
  program; the copy re-earned (and silently lost) what the parent earned
  (receipts j-36f78c, j-c93562, #195, #196).
- **A station is one `[[stage]]`, any topology.** Fan-out stages are
  stations too — one word because they are managed identically.
- **An engine is a per-topology loop, hosted in-process at each
  station.** Engines stay decoupled behind a narrow hosting contract:
  the station folder, the shared `data/` shelf, scoped rail verbs —
  never a sibling station, never the run root.
- **The placement law:** an artifact lives with the station that owns
  its meaning; it is promoted to `data/` exactly when a later station
  or the report must read it; program bytes and run bookkeeping live at
  the root; accounting lives on the events trace, never the run tree;
  `delegations/` is for real cross-program commissions only.
- **The mailbox is per-agent.** `mailbox/<agent>/` — only the owner
  writes (path rules, not promises); everyone else reads.
- **Sending happens through a TOOL, not a protocol.** The send tool is
  bound to the pane's identity at birth, validates the shape, refuses
  any folder but its owner's, and assigns the sequence number itself.
  The wire format is a function call, not prose the model imitates.
- **The ledger is rail-written only.** Agents never write it. The tool
  gives convenience and correctness; the rail gives truth. Even a pane
  that raw-writes its own folder bypassing the tool cannot touch the
  ledger or anyone else's folder.
- **Structure was deterministic; discipline was not** (13 gap marks vs
  zero, same brief, same model). Prose rules are advice, not machinery.
- **Questions are a bank, not behavior.** `questions.toml` is committed
  with the program; runs inherit the exact questions and may APPEND
  (append-only, `retired = true`, never erasure); the audit checks
  every asked question is banked. The brief's "same questions every
  run" becomes true by construction.
- **Detection is a script; repair is the producer; a judge never
  writes.** The deterministic audit detects (fresh context, verbatim
  errors). The ORIGINAL pane repairs, handed the verbatim error with
  its full context (the missing-file class needs the producer's
  context; a fresh agent would fabricate). An LLM judge, if ever added,
  is advisory-only.
- **The wake is a repair ticket, not a death certificate.** A parked
  run's wake carries the verbatim why, the failed artifact, and ONE
  line: the cheapest next command. "Program changed since booking?" is
  a content-hash comparison the booking already stores. Self-cure is
  proven: `whl continue` re-ran job j-93d652's report green in ~30s,
  zero tokens.
- **The door books the job id AFTER all screens pass.** No phantom
  aborted rows (three were minted this session by probe runs).
- **Audits run before panes retire** (#198): a verdict that could be
  fixed by one more turn must meet a living pane.
- **Zens deal in conflict.** When a design choice meets a zen line, the
  question is "is the zen wrong, or am I?" — and either way the record
  shows the reasoning (SUPERSEDED / REJECTED / SPLIT marks, never
  erasure).
- **Session→meta is a skill** (yyx-project-meta): fresh-mind
  distillation of rulings, MECE aspects, append-only zens, checkpointed
  ranges. Anchor-style continuation REJECTED (context pollution).

## Coinages (→ CONTEXT.md)

- **Station** — one stage of the chain, any topology.
- **Repair ticket** — a wake that names the fix and the next command.
- **Question bank** — committed questions a run inherits and grows.

  (partial context produces plausible-wrong files; repair belongs to
  the producer; judges advise only).
- Anchor-based meta updates (continue the same context over and over)
  — rejected (waste, pollution; fresh distillations of bytes).
- "Even if admission was missed, runtime permission would pass it" —
  rejected (receipt j-a532f9: uncovered paths become gray-zone asks
  that burn the sweep to the deny cap).

# herdr Brownout Guard: stagger, retry, and the named doorbell

One multiplexer (herdr) holds every pane. The 2026-10-12 p10 batch proved both failure modes of that single dependency in one morning: at 09:51 seven spurs asked for panes in the same second — a stampede herdr choked on — and the engine had zero retry, so a first refusal was death (wave 1); and at wake time, a brown herdr fails the parent-pane prompt and the fork spawn together, leaving the doorbell (a human's phone) as the only rung that worked (the wave-3 near-miss). Considered: a global admission queue across jobs (rejected — cross-process coordination for a seconds-long condition); queueing births to a daemon (rejected — a second scheduler to babysit); doing nothing (rejected — the storm is one batch-size launch away). Adopted, three primitives in `src/backoff.ts`:

1. **Stagger** — every pane birth (`inhabitPane`) first sleeps a uniform random pause, default bound 1500ms (`AGENTIC_OS_BIRTH_JITTER_MS`; 0 disarms), so a batch arrives as a queue, not a stampede.
2. **Retry with growing pauses** — a refused `herdr agent start` knocks again: default 3 attempts at base 5s, then ×3 (`AGENTIC_OS_START_TRIES`, `AGENTIC_OS_START_BACKOFF_MS`). The wake-side fork rung gets the same loop (`AGENTIC_OS_FORK_TRIES`, `AGENTIC_OS_FORK_BACKOFF_MS`), and every retry lands in the rung trace (`brownout retry N/M in Xms`) — the ladder's no-silence rule extends to the pauses themselves. An injected port is retried too, but under node:test the defaults collapse to a single attempt and zero pause unless a test names its own scale.
3. **The named doorbell** — `whl audit` lists every job whose wake fell out of band (`doorbell`/`queued`, never consumed) with the fork rung's diagnosis and the drain verb (`agentic-os fork <jid>`), and fails the audit exit code. The doorbell stays a last resort; it stops being a silent one.

The pauses are synchronous (`Atomics.wait` — no subprocess): the engines are synchronous by design (spawnSync CLIs), and a bounded blocking pause is the in-process price of surviving a brownout — worst case a birth blocks ~20s, versus the old behavior of dying in ~0.

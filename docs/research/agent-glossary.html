0 — The big idea this OS banks on

The field's unresolved tension: agents are flexible but expensive and hard to trust; workflows are trustworthy but handwritten. This repo's answer — use the agent once, at compile time; use the workflow many times, at run time.

a task
cold text, or a project task with roots.txt scope
Composer Actor
an agent, once — plans the task into a program folder
agentic-program/
dag.mjs · workflow.toml · hooks/ — reviewable, versioned, diff-able

human approves the plan before anything runs
run door → Rail
deterministic DAG runs, report + trace every time
agent time — flexible, once
workflow time — predictable, many
Airflow DAGs are handwritten by humans. Here the DAG is the agent's output artifact — plan-and-execute taken literally. That's the elevator pitch no competitor has.

2 — Tradeoffs — the interview spine

Interviewers probe the choice, not the definition. Drill these until the decision rules are reflexes.
